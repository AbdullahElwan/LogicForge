## 📌 Overview

**LogicForge** is a Discrete Mathematics project that focuses on analyzing and proving the **logical equivalence of complex Boolean expressions** using both theoretical and computational approaches.

The system generates full truth tables and validates results through a **C++ implementation**, ensuring accuracy and consistency.

---

## 🧠 Project Objective

To prove the equivalence between two complex Boolean expressions using:

* Truth Table Analysis (LHS vs RHS)
* Logic Gate Representation
* Computational Verification using C++

As shown in the project, both sides of the equation produce identical results, confirming logical equivalence 

---

## 🚀 Key Features

### 📊 Truth Table Generation

* Generates complete truth tables for multiple variables (P, Q, R, C)
* Displays both symbolic and numeric representations

### 🔍 Logical Equivalence Verification

* Compares Left-Hand Side (LHS) and Right-Hand Side (RHS)
* Ensures identical outputs across all cases

### ⚙️ C++ Implementation

* Automates truth table generation
* Eliminates manual calculation errors
* Efficient and structured logic evaluation

### 🔌 Logic Gate Representation

* Visual representation of Boolean expressions using logic gates
* Demonstrates real-world circuit mapping
